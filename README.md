## FAQ

### What is XCutors?

XCutors is a collection of popular Roblox script executors bundled together with a universal loader, making it easy to manage and switch between different executors on Windows.

### Is XCutors free to use?

Yes, XCutors is completely free and open-source. All included executors are freely available community tools.

### What Windows versions are supported?

XCutors supports Windows 10 (version 1903 and later) and Windows 11. Both 32-bit and 64-bit editions are compatible.

### How do I update the executors?

The universal loader (xcutorsLoader) includes an auto-update feature that checks for new versions of all included executors. You can also manually download updates from the Releases page.

### Where can I find scripts to use?

XCutors includes a built-in script library with popular community scripts. You can also find scripts on community forums, script repositories, and Discord servers dedicated to Roblox scripting.

### Why is my anticomponent flagging XCutors?

Some anticomponent software may flag script executors as potentially unwanted programs due to their nature of injecting code into other processes. This is a false positive. You may need to add an exception in your anticomponent settings.

### Can I use XCutors without the universal loader?

Yes, each executor can be launched independently. However, using xcutorsLoader is recommended for easier management, updates, and switching between executors.

### Which executor should I choose?

Each executor has different strengths. Synapse Z is known for stability, Volt offers fast execution, Potassium has a user-friendly interface, and Wave provides broad script compatibility. Try each to find what works best for your needs.

### How do I add custom scripts to the library?

Navigate to the 'scripts' folder within your XCutors installation directory and place your .lua or .txt script files there. They will automatically appear in the loader's script library.

### The executor is not attaching to Roblox. What should I do?

Ensure Roblox is running before clicking attach, run the executor as Administrator, disable any conflicting anticomponent software temporarily, and make sure you're using the latest version of XCutors.
